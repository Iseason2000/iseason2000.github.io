# 自动解绑

自动解绑有两种配置入口：

- `global-setting.yml` / `settings.yml` 中的 `auto-unbind`：随绑定设置生效，适合“这类物品绑定后在某个行为时解绑”。
- `modules/auto-unbind.yml`：独立模块，会额外检查已绑定物品是否匹配对应事件的 matcher，适合集中配置解绑规则。

:::warning[性能提示]

该模块会对触发事件中的绑定物品执行额外匹配。只在确实需要跨设置统一解绑规则时开启。

:::

## 触发事件

| 配置 | 触发 |
| --- | --- |
| `onClick` | 点击物品 |
| `onPickup` | 捡起物品 |
| `onDrop` | 丢弃物品 |
| `onUse` | 使用物品消耗耐久 |
| `onLeft` | 手持物品左键 |
| `onRight` | 手持物品右键 |
| `onEquipWear` | 装备穿戴，仅 Paper 及下游服务端 |
| `onScanner` | 扫描器扫描背包 |

## 配置文件

```yaml title="modules/auto-unbind.yml"
# 自动解绑模块
# 识别已绑定的物品，并在玩家进行特定行为时解绑。
# 此功能会对每一个绑定物品进行检测，建议只在需要时开启
# xxMatcher 的格式与 setting.yml 的格式一致
readme: ''

# 功能总开关
enable: false

# 是否点击物品时解绑
onClick: false
onClickMatcher: {}

# 捡起物品时解绑
onPickup: false
onPickupMatcher: {}

# 丢弃物品时解绑
onDrop: false
onDropMatcher: {}

# 使用物品消耗耐久时解绑(包括工具、武器、盔甲等有耐久的物品)
onUse: false
onUseMatcher: {}

# 手拿物品左键时解绑
onLeft: false
onLeftMatcher: {}

# 手拿物品右键时解绑
onRight: false
onRightMatcher: {}

# 装备物品穿戴时解绑(仅限Paper及其下游服务端核心)
onEquipWear: false
onEquipWearMatcher: {}

# 扫描器扫描时解绑(在config.yml中配置扫描器)
onScanner: false
onScannerMatcher: {}

# 匹配完的物品会缓存结果, 此处设置最大缓存的数量, 重启生效
cacheSize: 800
```

## 示例

让 lore 中包含 `临时绑定` 的已绑定物品在扫描器扫描时自动解绑：

```yaml title="modules/auto-unbind.yml"
enable: true
onScanner: true
onScannerMatcher:
  temporary:
    match:
      lore-without-color:
      - 临时绑定
```

`onClickMatcher`、`onPickupMatcher` 等 matcher 的结构与 `settings.yml` 中 `matchers.<id>` 一致，实际只需要 `match` 节点即可。
