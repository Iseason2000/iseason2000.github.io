# 权限

## 命令权限

命令权限由命令节点自动生成，格式为 `sakurabind.<节点1>.<节点2>`，节点名会转为小写。

| 命令 | 权限 | 默认 |
| --- | --- | --- |
| `/sakurabind` | `sakurabind.sakurabind` | 所有人 |
| `/sakurabind getLost` | `sakurabind.sakurabind.getlost` | 所有人 |
| `/sakurabind callback` | `sakurabind.sakurabind.callback` | 所有人 |
| `/sakurabind test match` | `sakurabind.sakurabind.test.match` | OP |
| 其他管理命令 | `sakurabind.sakurabind.<节点名小写>` | OP |

通配权限 `sakurabind.sakurabind.*` 拥有根命令下全部子命令权限。

权限插件中如果设置了显式拒绝，可能覆盖 Bukkit 的默认权限。普通玩家无法执行 `/sakurabind getLost` 或 `/sakurabind callback` 时，优先检查权限插件是否对 `sakurabind.sakurabind.getlost`、`sakurabind.sakurabind.callback` 写了 `false`。

## 绑定绕过

:::danger[OP 会跳过自动绑定]

OP 默认拥有 `sakurabind.bypass.all`。如果你用 OP 账号测试自动绑定，插件会跳过扫描器、点击、捡起、丢弃、使用、装备等自动绑定监听，表现就是“怎么点都不绑定”。

排查自动绑定时，先用非 OP 玩家测试；或者在 LuckPerms 等权限插件中对测试玩家显式设置 `sakurabind.bypass.all` 为 `false`。

:::

| 权限 | 作用 |
| --- | --- |
| `sakurabind.bypass.all` | OP 默认拥有；不受绑定物品、方块、实体的行为限制 |
| `sakurabind.bypass.<玩家UUID>` | 让权限持有者在行为检查中被视为该 UUID 物主，适合多人共用绑定物品；不改变物品找回归属 |

拥有 `sakurabind.bypass.all` 的玩家也会被扫描器跳过，因此不会触发扫描器自动绑定、扫描器自动解绑或扫描送回。手动执行 `/sakurabind bind ...` 这类管理命令仍然可以绑定物品。

## 设置权限

除 `sakurabind.bypass.all` 外，以下设置权限只有在 `config.yml` 开启 `enable-setting-permission-check` 后才会参与判定。

| 权限 | 作用 |
| --- | --- |
| `sakurabind.settings.<配置键>.true` | 将全局布尔设置强制判定为 `true` |
| `sakurabind.settings.<配置键>.false` | 将全局布尔设置强制判定为 `false` |
| `sakurabind.setting.<匹配器名>.<配置键>.true` | 只覆盖某个 `settings.yml` 匹配器下的布尔设置 |
| `sakurabind.setting.<匹配器名>.<配置键>.false` | 只覆盖某个 `settings.yml` 匹配器下的布尔设置 |

示例：

```text
sakurabind.settings.item-deny.drop.true
sakurabind.setting.example.item-deny.click.false
```

设置权限的优先级高于 `settings.yml` 和 `global-setting.yml`。特定匹配器权限优先级高于全局设置权限。

开启 `enable-setting-permission-check` 后，布尔设置读取顺序为：

1. `sakurabind.setting.<匹配器名>.<配置键>.true|false`
2. `sakurabind.settings.<配置键>.true|false`
3. `settings.yml` 中当前匹配器的配置
4. `global-setting.yml`

`sakurabind.bypass.all` 不依赖 `enable-setting-permission-check`，始终生效。

## LuckPerms 示例

给普通玩家领取暂存箱权限通常不需要额外设置，因为默认已有：

```text
sakurabind.sakurabind.getlost
sakurabind.sakurabind.callback
```

给管理员全部命令：

```text
/lp user Admin permission set sakurabind.sakurabind.* true
```

给某个玩家绕过所有绑定限制：

```text
/lp user Admin permission set sakurabind.bypass.all true
```

临时取消测试玩家的 OP 绕过，方便测试自动绑定：

```text
/lp user Tester permission set sakurabind.bypass.all false
```

开启 `config.yml` 的 `enable-setting-permission-check: true` 后，让某组玩家可以丢弃绑定物品：

```text
/lp group vip permission set sakurabind.settings.item-deny.drop.false true
```

只针对 `legend_sword` 匹配器允许丢弃：

```text
/lp group vip permission set sakurabind.setting.legend_sword.item-deny.drop.false true
```

## 配置键怎么写

权限里的 `<配置键>` 使用配置文件中的完整路径，用 `.` 连接层级。

```yaml
item-deny:
  drop: true
```

对应：

```text
sakurabind.settings.item-deny.drop.true
```

`@` 不写进权限节点。权限覆盖的是布尔结果本身，不参与 `@` 取反规则。
