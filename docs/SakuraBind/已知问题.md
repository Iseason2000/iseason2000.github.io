# 已知问题

>  插件无法解决的问题



* spigot1.12.2以下的版本由于`Sqlitejdbc`旧版本被内嵌在服务端内，导致无法使用，请使用非sqlite连接数据库
* spigot1.8.x 版本的配置编码会乱码，请自行更改编码或在服务端启动参数里加上 `-Dfile.encoding=UTF-8`
* 首次启动和切换数据库类型时需要下载运行库或数据库驱动，离线服务器需要提前准备 `libraries`
* 部分mod服务端的漏斗、发射器禁用功能失效
* `superCallback` 只扫描在线玩家背包、末影箱、世界掉落物和已加载容器，不扫描离线玩家数据
* `superCallback` 会扫描掉落物和已加载容器，玩家多或加载区块多时建议低峰期使用
* 唯一物品防刷仍属于实验性功能，不建议直接用于生产环境高价值物品
* 如果 `send-back-queue` 所有途径都失败，剩余物品无法继续保存，有丢失风险
* 删除 `plugins/SakuraBind/data` 可能导致已放置方块或已存在实体的绑定数据丢失
* 装备穿戴自动绑定/解绑仅 Paper 或下游服务端可用
