# 实用配置方案

本页提供可直接复制的常见配置。复制前先确认缩进，YAML 对缩进敏感。

## 方案一：只保护某类高级武器

目标：

- 只绑定名字含 `传说` 的剑。
- 点击或扫描时自动绑定。
- 非物主不能丢弃、拿走、捡起。
- 物主可以正常操作。

```yaml title="settings.yml"
matchers:
  legend_sword:
    match:
      material: '.*_SWORD'
      name-without-color: '.*传说.*'
    settings:
      auto-bind:
        enable: true
        onClick: true
        onScanner: true
      item-deny:
        drop@: true
        click@: true
        pickup@: true
      item:
        send-back-scanner: true
        send-back-on-pickup: true
```

保存后执行：

```text
/sakurabind reload settings.yml
```

## 方案二：绑定物品丢失后优先发邮箱

目标：

- 玩家在线时先进背包。
- 背包放不下时发 SweetMail。
- 邮件失败再进暂存箱。

```yaml title="config.yml"
send-back-database: true
send-back-queue:
- player
- SweetMail
- database

sweet-mail:
  sender: 绑定系统
  icon: BOOK
  title: 绑定物品返还
  content:
  - |-
    你的绑定物品已被系统找回。
    请及时查收。
  expire: -1
```

需要安装 SweetMail。没有安装时，该途径会不可用，插件会继续尝试后面的 `database`。

## 方案三：禁止绑定物品进入垃圾桶

目标：

- 容器标题为 `垃圾桶` 时禁止放入绑定物品。
- 同时禁止点击，减少绕过。

```yaml title="global-setting.yml"
item-deny:
  inventory: true
  inventory-pattern:
  - '^垃圾桶$'
```

如果只想限制某类物品，把这段放进 `settings.yml` 对应匹配器的 `settings` 下。

## 方案四：绑定方块，物主可使用，其他人不能动

先开启方块监听：

```yaml title="config.yml"
block-listener: true
```

重启服务端。

配置方块限制：

```yaml title="global-setting.yml"
block-deny:
  break@: true
  place@: true
  interact@: true
  explode: true
  piston: true
  flow: true
```

绑定玩家前方方块：

```text
/sakurabind bind block Steve
```

## 方案五：绑定刷怪蛋生成的实体

先开启实体监听：

```yaml title="config.yml"
entity-listener: true
```

重启服务端。

配置实体规则：

```yaml title="global-setting.yml"
entity:
  bind-name: '&a{0} &f的 &7{1}'
  spawn-egg-check: true
  bind-drops: true

entity-deny:
  damage-by-player@: true
  interact@: true

entity-deny-ai: false
entity-deny-gravity: false
entity-deny-drops: false
```

如果希望绑定实体死亡掉落物也绑定，保留 `entity.bind-drops: true`。

## 方案六：从旧 lore 绑定迁移

旧插件 lore 示例：

```text
[绑定]: Steve
```

迁移配置：

```yaml title="modules/migration.yml"
enable: true
scanning-period: 10
match-lore:
- '\[绑定]: (.*)'
lore-is-uuid: false
force-bind: false
remove-lore: true
dont-bind: false
bind-setting: ''
cache-size: 2000
```

迁移完成后关闭：

```yaml
enable: false
```

## 方案七：制作绑定道具

开启模块：

```yaml title="modules/bind-item.yml"
enable: true
```

重启服务端。

将手持物品标记为绑定道具，成功率 100%：

```text
/sakurabind autoBind sakura_bind_bind-item
```

将手持物品标记为绑定道具，固定绑定为 `legend_sword` 设置：

```text
/sakurabind autoBind sakura_bind_bind-item legend_sword
```

将手持物品标记为解绑道具，只能解绑 `legend_sword`：

```text
/sakurabind autoBind sakura_bind_unbind-item legend_sword
```

玩家把道具放在鼠标指针上，点击目标物品即可触发。

## 方案八：只给管理员绕过限制

给管理员：

```text
sakurabind.bypass.all
```

给某个团队成员共享指定玩家 UUID 的绑定物：

```text
sakurabind.bypass.<玩家UUID>
```

第二种权限只让行为检查视为物主，不会改变物品真正归属，也不会改变找回目标。

## 方案九：排查匹配器为什么没生效

手持目标物品，执行：

```text
/sakurabind test tryMatch legend_sword
```

输出会显示每个匹配项的目标值、物品实际值和匹配结果。

查看手持物 NBT：

```text
/sakurabind nbt
```

输出在服务端控制台，不在聊天栏。
