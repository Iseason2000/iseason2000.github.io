# 命令

根命令是 `sakurabind`，别名为 `sbind`、`sb`、`sab`、`bind`。

命令节点会按权限显示可用子命令。对非叶子节点执行命令时，会输出该节点下可用的子命令；大多数命令可以在末尾附加 `-silent` 来隐藏插件提示消息。

`bind` 与 `bindTo` 的区别：

| 命令 | 选择目标的位置 | 绑定给谁 |
| --- | --- | --- |
| `/sakurabind bind ... <player>` | 目标玩家的手持物品、前方方块或前方实体 | 目标玩家 |
| `/sakurabind bindTo ... <player>` | 执行者自己的手持物品、前方方块或前方实体 | 命令中的目标玩家 |

## 玩家默认可用

| 命令 | 作用 |
| --- | --- |
| `/sakurabind getLost` | 领取暂存箱中的遗失物品 |
| `/sakurabind callback` | 切换个人物品召回模式 |

`getLost` 有 1 秒冷却。背包放不下时只会取出能放下的数量，剩余物品继续留在暂存箱数据库。

`callback` 只切换当前运行期间的个人召回模式，重启服务端后不会保留。

## 管理命令

| 命令 | 作用 |
| --- | --- |
| `/sakurabind bind <item\|block\|entity> <player> [setting] [-noLore]` | 将指定玩家手持物品、前方方块或前方实体绑定给该玩家 |
| `/sakurabind bindTo <item\|block\|entity> <player> [setting] [-noLore]` | 执行者选择自己手持物品、前方方块或前方实体，并绑定给目标玩家 |
| `/sakurabind bindAll <player> [-noLore]` | 绑定目标玩家背包内全部物品 |
| `/sakurabind unBind <item\|block\|entity> <player>` | 解绑目标玩家手持物品、前方方块或前方实体 |
| `/sakurabind unBindAll <player>` | 解绑目标玩家背包内全部物品 |
| `/sakurabind autoBind [nbtKey] [nbtValue]` | 给手持物品写入自动绑定或模块道具用的 NBT |
| `/sakurabind select <player> [bind]` | 为目标玩家切换选择模式；追加 `bind` 后绑定已选择目标 |
| `/sakurabind openLost <player\|uuid> [page]` | 打开并编辑某个玩家或 UUID 的暂存箱页面，页码默认 `1` |
| `/sakurabind superCallback <player>` | 扫描在线玩家背包、末影箱、掉落物和已加载容器，并召回目标玩家的绑定物品 |
| `/sakurabind reload [file]` | 重载全部配置；指定文件时只重载该配置文件 |
| `/sakurabind debug [player]` | 切换全局 debug，或切换指定玩家的动作检查 debug |
| `/sakurabind nbt` | 将手持物品 NBT/序列化信息输出到控制台 |
| `/sakurabind cache` | 输出物品匹配缓存、迁移模块缓存、自动解绑模块缓存统计 |

## 测试命令

| 命令 | 作用 |
| --- | --- |
| `/sakurabind test match [count]` | 多次匹配手持物品并输出耗时与命中的设置 |
| `/sakurabind test tryMatch <setting>` | 使用指定 `settings.yml` 匹配器测试手持物品，并输出每个匹配项结果 |

## 参数说明

`<item|block|entity>` 中，`entity` 绑定和解绑只在 Minecraft `1.13+` 可用；`block` 与 `entity` 行为还需要分别在 `config.yml` 开启 `block-listener`、`entity-listener`。

`[setting]` 是 `settings.yml` 中 `matchers` 的键名。留空或键名不存在时，插件会按物品匹配器自动识别；方块和实体默认使用 `global-setting`。

`[-noLore]` 只影响命令绑定物品时是否写入绑定 lore，不影响 NBT 物主信息。

`openLost` 会在关闭界面时把界面中的物品重新写回该玩家暂存箱。它适合管理员检查或编辑暂存箱内容，操作前确认打开的是正确玩家或 UUID。

`superCallback` 会同步获取世界掉落物和已加载容器数据，并扫描其他在线玩家背包与末影箱。玩家多、已加载区块多时可能有明显开销，建议在低峰期使用。

## 常用示例

绑定玩家手上的物品：

```text
/sakurabind bind item Steve
```

绑定玩家手上的物品，并强制使用 `legend_sword` 设置：

```text
/sakurabind bind item Steve legend_sword
```

把自己手上的物品绑定给别人：

```text
/sakurabind bindTo item Steve
```

绑定玩家前方方块：

```text
/sakurabind bind block Steve
```

解绑玩家背包内所有物品：

```text
/sakurabind unBindAll Steve
```

只重载 `settings.yml`：

```text
/sakurabind reload settings.yml
```

打开某个 UUID 的暂存箱第一页：

```text
/sakurabind openLost 00000000-0000-0000-0000-000000000000 1
```

排查手持物为什么匹配不到：

```text
/sakurabind test tryMatch legend_sword
```

:::note

`-silent` 是命令框架的统一参数，但少数命令仍会输出结果或控制台信息，例如 `cache`、`nbt`、测试命令，以及部分自定义提示。

:::
