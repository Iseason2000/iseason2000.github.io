# 下载与安装

## 环境要求

:::danger[注意]

请不要热加载插件。首次启动或切换数据库类型时，插件可能联网下载运行库。

:::

| 项目 | 要求 |
| --- | --- |
| Java | Java 8 或以上 |
| 服务端 | Spigot API 1.8 或以上，以及 Paper/Purpur 等下游服务端 |
| 当前源码版本 | `2.4.10` |

`1.7.10` 仅 legacy 分支有部分支持：[2.4.0-legacy](https://github.com/SakuraTown/SakuraBind/releases/tag/2.4.0-legacy)。

Paper/Purpur 不是必需项，但在 Paper 或下游服务端上会额外启用装备穿戴检测，`auto-bind.onEquipWear` 和 `auto-unbind.onEquipWear` 才有意义。

## 安装

1. 关闭服务端。
2. 安装必需依赖 `NBTAPI`，并按需安装软依赖插件。
3. 将 `SakuraBind.jar` 放入 `服务端根目录/plugins/`。
4. 启动服务端，等待运行库下载、数据库连接和配置生成完成。
5. 关闭服务端，备份并编辑 `plugins/SakuraBind/` 下的配置文件。
6. 再次启动服务端，确认控制台没有依赖、数据库或 YAML 解析报错。

开启或关闭 `block-listener`、`entity-listener`、模块总开关、日志文件路径等重启生效项后，需要重启服务端。

:::tip[离线服务器]

插件会在首次启动和切换数据库类型时下载 Kotlin、Exposed、HikariCP、数据库驱动等运行库，默认放在服务端根目录的 `libraries`。如果服务器不能访问 Maven 仓库，请先在网络正常的同版本测试环境启动一次，再复制 `libraries` 目录到正式服。

:::

## 安装后检查

启动后检查控制台：

- 没有 `NBTAPI` 缺失报错。
- 没有数据库连接失败报错。
- 出现 `SakuraBind` 启用成功日志。
- `plugins/SakuraBind` 目录已经生成配置文件。
- 默认 H2 数据库文件 `plugins/SakuraBind/database/database_sakurabind.mv.db` 可正常创建。

进入游戏后执行：

```text
/sakurabind
```

如果能看到子命令列表，说明命令已注册。

再执行：

```text
/sakurabind getLost
```

普通玩家默认应能使用该命令。若提示没有权限，请检查权限插件是否覆盖了默认权限。

## 第一次配置建议

新服建议先保持默认只启用物品绑定，确认没有报错后再按需开启：

- 方块绑定：`config.yml` 的 `block-listener`
- 实体绑定：`config.yml` 的 `entity-listener`
- 绑定道具：`modules/bind-item.yml`
- 唯一物品：`modules/unique-item.yml`
- 数据迁移：`modules/migration.yml`

`settings.yml` 默认带有 `example` 演示匹配器。正式使用前建议删除、注释或改成自己的匹配器，避免示例规则误命中真实物品。

默认全局设置会禁止绑定物品参与合成：

```yaml title="global-setting.yml"
item-deny:
  craft: true
```

如果你的玩法允许绑定物品合成，需要明确改成 `false`，或只在特定 `settings.yml` 匹配器中覆盖。
