# 占位符

安装 PlaceholderAPI 后，插件会注册 identifier `sakurabind`。占位符说明也会生成在 `plugins/SakuraBind/placeholders.txt`。

| 占位符 | 作用 |
| --- | --- |
| `%sakurabind_has_lost%` | 判断玩家是否有暂存箱记录；缓存 3 秒，返回 `true` 或 `false`，数据库未连接时返回 `null` |
| `%sakurabind_lost_count%` | 返回玩家暂存箱数据库记录数；缓存 1 秒，数据库未连接时返回 `null` |
| `%sakurabind_hasbind_held%` | 判断在线玩家手持物品是否绑定；有绑定返回 `true`，无绑定返回 `false`，无手持物返回 `null` |
| `%sakurabind_owner_uuid_held%` | 获取在线玩家手持物品的物主 UUID；无手持物或无绑定返回 `null` |
| `%sakurabind_owner_name_held%` | 获取在线玩家手持物品的物主名称；无手持物或无绑定返回 `null` |

`lost_count` 统计的是数据库记录数，不等同于物品总数量；一个记录内可能包含多件物品。
